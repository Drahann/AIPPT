# 创赛 PPT 风格圣经 · CODEX

> **版本 v1.0（理解循环 R1–R3 收敛定稿）**
> 证据：~50 套真实国金级模板 + 8 套通用BP对照，跨 6 色系；COM 渲染(装 299 字体)+ python-pptx 三轮量化。
> 权威级别：**SVG/XML 实测 > 本文 > 直觉**。数据源 `metrics/R1-R3_*`、`renders/`、`contact_sheets/`、`loop/R1-R3_notes.md`。
> 用途：①回答"创赛 vs AI 差在哪"②作为 BUILD 阶段(ppt-master brand/layout)的硬规格。

## Part 0 · 一句话 + 密度光谱

**创赛 PPT = "致密合成的视觉战场" + "学院化的官方身份" + "家族化的浓饱皮肤"。** AI 做的是"干净的信息板"。

**密度光谱（形状/页，硬证据）**：
```
普通 AI-PPT  8–20  │  通用商业计划书/路演模板 ~30  │  创赛 50–130（红旅~50 最低，科技/黑金 109–130 最高）
   留白透气           商务干净(雅黑/Arial)              致密合成(家族展示体)
```
> 关键：连"通用 BP 模板"都只有 ~30、用雅黑——**它更靠近 AI**。创赛的独特性不是"商务好看"，而是 ↓Part I 七条。

## Part II · 共同结构语法（跨色系不变量 = 可编码骨架）

> 6 色系共享同一骨架，仅**换肤**(配色/字体/装饰/背景)。这是 ppt-master 里"一套 layout + 每色系一个 brand"的依据。

1. **赛事 chrome 层**：封面顶部赛事全名条 + 赛事 logo；**校徽常驻每页一角**。
2. **封面解剖**：超大展示标题(金渐变/辉光/描边，常带手绘 flourish) + 一句副标(常用 / 或 · 分隔) + **参赛信息 pill 块** + 满铺照片或氛围暗场。
3. **页标题装置（二选一）**：A=圆角深色**页眉牌**(科技，常配 «») ｜ B=左上**黑色斜切 banner** + 英文副标(非遗/农业/通用/红旅)。
4. **底部常驻条**：科技/医疗=**章节 section-nav**(当前高亮)；红旅=**红绸带+祥云**；通用=简版页脚。
5. **三栏合成正文**：面板(辉光/HUD/玻璃/实线框)×3，每面板=**徽章+标题+正文+pill按钮+图**的小宇宙；背景持续氛围层，从不纯平。
6. **金句 ribbon**：内容页底整幅色条，大字结论 + 关键词异色(金/朱)。**这是创赛页的"句号"**，AI 从不做。
7. **节奏切换**：叙事/封面/章节页深或满铺(放空)；**数据页常切浅/白底 + 家族色描点**(保图表可读)。
8. **强中心对称、三栏为王**；元素**贪婪填满**到安全边再换行，列底撑到金句条上沿。

## Part III · 页面原型库（archetypes）

> 典型序列：封面 →(版权声明)→ 目录 → 章节过渡 → [背景/痛点 → 方案/技术 → 数据/成果 → 商业模式] → 团队 → 结尾。

| 页型 | 构图规则（实测观察） |
|---|---|
| **封面** | Part II.2。展示标题占据视觉中心，副标 + 参赛 pill 块 + 满铺图/暗场 + 赛事chrome。|
| **目录 TOC** | 环形/编号菜单（01–04 围绕中心字）或竖列大编号 + 章节名 + 英文。深底，疏。|
| **章节过渡** | 巨大 `壹/01` 或章节号 + 章节名 + 英文小字，深底，极简（**锚点放空页**）。|
| **背景/痛点** | 黑斜切banner标题 + 中国地图/数据/剪报 + 痛点要点框，常"一图读懂"。|
| **方案/技术** | 中央设备/产品"舞台"(3D基座/mockup) + 左右框面板 + 流程箭头 + 金句条。|
| **数据/成果** | 图表(3D金柱/折线/饼) + 巨型汉字数字水印 + 大数字 + 麦穗框指标pill + 趋势手绘ribbon + 底金句。常浅/白底。|
| **商业模式** | 多模块框 + 蓝/金连线 + 箭头闭环；保持家族皮肤。|
| **团队** | 人像(圆/方框) + 姓名(800重) + 角色 + 组织架构网格；纵向铺满。|
| **结尾** | `谢谢观看/感谢聆听` 巨字 + 联系方式/二维码/手机mockup + 家族底饰。|

- **现代黑体系**（科技/医疗/农业/黑金）：正文 **思源黑体CN / 阿里巴巴普惠体 / HarmonyOS Sans / OPPOSans**；标题 **优设标题黑 / 汉仪菱心体简(农业)**；数据 **阿里妈妈数黑体**。无衬线。

## Part VI · "把 AI-PPT 改造成创赛"的可执行清单（→ 指导 BUILD）
1. 选**字脉+色系皮肤**(6 选 1)，锁死家族 hex 调色板与展示/正文字体。
2. 铺**非纯平背景**(氛围暗场/满铺照片/宣纸)，多层(辉光+粒子+网格)。
3. 加**赛事 chrome**：封面赛事条+logo、常驻校徽、参赛信息pill块。
4. 页标题用**页眉牌或黑斜切banner**(+英文副标)；不要居中裸标题。
5. 正文走**三栏合成面板**，每面板塞满(徽章+标题+正文+pill+图)，密度拉到 50+。
6. 内容页底加**金句 ribbon**(关键词异色)。
7. 标题做**金渐变+发光+描边**，可单字异色、挂 motif、配英文译名+品类标签。
8. 配**真实人物场景照**(满铺/内嵌/曲线图片带)，统一压暗调色。
9. 数据页切**浅/白底 + 家族色描点 + 数字水印 + 麦穗指标框**。
10. 节奏：封面/章节**放空**，内容页**填满**——这才是创赛的"呼吸"。
